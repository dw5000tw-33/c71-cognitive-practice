## 📲 下載與安裝

1. 掃描上方 QR Code，或點選「下載最新版 APK」。
2. 進入 Release 頁面後，在 **Assets** 區塊點選檔名結尾為 `.apk` 的檔案。
3. 下載完成後，點開 APK。
4. 手機若顯示「基於安全考量，目前不允許安裝未知應用程式」，請點 **設定**。
5. 開啟「允許來自此來源的應用程式」或「允許安裝未知應用程式」。
6. 返回安裝畫面後，點選 **安裝**。
7. 安裝完成後，點選 **開啟**。

> Android 顯示未知來源警告，是因為此 App 不是從 Google Play 商店安裝，不代表檔案一定有問題。請只從本 GitHub Repository 的 Release 頁面下載，不要使用來路不明的轉傳網址或 APK。

## 📱 放到手機桌面

1. 回到手機主畫面。
2. 從畫面底部向上滑，打開「所有應用程式」。
3. 找到 **高齡認知練習**。
4. 長按綠色 App 圖示。
5. 拖曳到主畫面最容易看到的位置後放開。

若手機沒有「所有應用程式」頁面，請在主畫面左右滑動尋找 App 圖示。
