- 使用方式：安裝後可完全離線使用
- 畫面設計：直式、超大粗體、大按鈕
- App 圖示：33 Works 綠色商標
- 目前版本：`v1.0.0`

## 下載與安裝

1. 進入最新版 Release 頁面。
2. 在 **Assets** 區塊點選檔名結尾為 `.apk` 的檔案。
3. 下載完成後，點開 APK。
4. 手機若顯示「基於安全考量，目前不允許安裝未知應用程式」，請點 **設定**。
5. 開啟「允許來自此來源的應用程式」或「允許安裝未知應用程式」。
6. 返回安裝畫面後，點選 **安裝**。
7. 安裝完成後即可開啟 App。

> Android 顯示未知來源警告，是因為此 App 不是從 Google Play 商店安裝，不代表檔案一定有問題。請只從本 GitHub Repository 的 Release 頁面下載，不要使用來路不明的轉傳網址或 APK。

## 放到手機桌面

1. 回到手機主畫面。
2. 從畫面底部向上滑，打開「所有應用程式」。
3. 找到 **高齡認知練習**。
4. 長按綠色 App 圖示。
5. 拖曳到主畫面最容易看到的位置後放開。

若手機沒有「所有應用程式」頁面，請在主畫面左右滑動尋找 App 圖示。

## 適用裝置

- 主要測試裝置：realme C71
- 系統：Android
- 最低支援版本：Android 6.0 以上
- 建議：直式使用、開啟大字體或粗體也能操作
- 網路：安裝完成後不需要網路

## 目前功能

- 基本認知練習
- 地點選擇：家裡／大潤發百貨／監理站
- 十項物品短期記憶
- 兩分鐘倒數
- 記住四項以上判定通過
- 隨機時間畫時鐘
